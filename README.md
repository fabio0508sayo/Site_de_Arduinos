# Site de Arduinos

Portal técnico sobre **robôs industriais**, **sensores IoT**, **Arduino** e **ESP8266**, com tema de placa de circuito.

## Estrutura

```
index.html                  Página inicial
robos.html                  Catálogo de robôs
robos/*.html                Uma página por tipo de robô (7)
sensores.html               Catálogo de sensores com busca e filtros
sensores/*.html             Uma página por sensor (25)
arduino.html                Conceitos e 12 exemplos de código
desafios-arduino.html       Desafios 01 a 03
desafios-esp8266.html       Desafios 04 a 07 (expansão com ESP8266)
referencias.html            Fontes consultadas
css/style.css               Estilos (tema PCB)
js/main.js                  Menu, copiar código, filtros e simulação
IMG/                        Imagens, ilustrações dos sensores e favicon
videos/                     Vídeos da página inicial e dos desafios
```

Para ver o site, abra `index.html` no navegador (as fontes e os ícones vêm da internet).
