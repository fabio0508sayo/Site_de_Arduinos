3 Desafios de Automação com Arduino

Três projetos práticos que aplicam os conceitos de sensores, lógica condicional e controle de atuadores apresentados nesta página de Arduino: iluminação inteligente com botão, controle de distância com sensor ultrassônico e um painel de ambiente inteligente com temperatura e umidade.

Desafio 01 — Iluminação Inteligente

O primeiro desafio introduz o conceito de controle digital de LEDs utilizando um botão como entrada. O sistema lê o estado do botão e aciona ou desliga um LED automaticamente, trabalhando os conceitos de entrada/saída digital, resistores de pull-down e lógica booleana aplicada à eletrônica.

Lógica de funcionamento: botão pressionado → pino de entrada lê HIGH → Arduino processa o estado e envia sinal ao pino de saída → LED acende; botão solto → pino retorna a LOW → LED apaga.

Tensão: 5V

Resistor: 220Ω

LED Output: Pino 13

Botão Input: Pino 2

desafio-01.ino

const int pinoBotao = 2;
const int pinoLED   = 13;

void setup() {
  pinMode(pinoBotao, INPUT);
  pinMode(pinoLED,   OUTPUT);
}

void loop() {
  int estadoBotao = digitalRead(pinoBotao);

  if (estadoBotao == HIGH) {
    digitalWrite(pinoLED, HIGH); // LED acende
  } else {
    digitalWrite(pinoLED, LOW);  // LED apaga
  }
}

Desafio 02 — Distância & Iluminação

O sensor ultrassônico HC-SR04 emite pulsos de 40kHz e mede o tempo de retorno do eco. A distância é calculada pela fórmula d = (t × 0,0343) / 2, onde t é o tempo do pulso em microssegundos. O sensor detecta objetos entre 2 cm e 400 cm, com precisão de ±3mm.

Um potenciômetro conectado ao pino A0 funciona como divisor de tensão variável, retornando valores entre 0 e 1023 que são mapeados para o brilho do LED com analogWrite(). A combinação sensor + potenciômetro cria um sistema em que a distância detectada altera dinamicamente o comportamento da iluminação.

desafio-02.ino

const int trigPin  = 9;
const int echoPin  = 10;
const int ledPin   = 6;   // PWM
const int potPin   = A0;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin,  OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Leitura do potenciômetro (limiar)
  int limiar = map(analogRead(potPin), 0, 1023, 5, 50);

  // Disparo do pulso ultrassônico
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Leitura do eco e cálculo da distância
  long duracao   = pulseIn(echoPin, HIGH);
  float distancia = duracao * 0.0343 / 2.0;

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.print(" cm | Limiar: ");
  Serial.println(limiar);

  // Controle do LED por distância
  if (distancia > 0 && distancia <= limiar) {
    analogWrite(ledPin, 255); // LED máximo
  } else if (distancia <= limiar * 2) {
    int brilho = map(distancia, limiar, limiar * 2, 200, 50);
    analogWrite(ledPin, brilho); // brilho proporcional
  } else {
    analogWrite(ledPin, 0);     // LED apagado
  }

  delay(100);
}

Desafio 03 — Ambiente Inteligente

O DHT11 (ou DHT22) é um sensor digital que mede temperatura e umidade relativa do ar por um protocolo de comunicação de um único fio, com precisão de ±2°C e ±5% UR. Neste desafio, o sistema lê continuamente o ambiente e aciona LEDs indicadores conforme os valores medidos, criando um painel visual de conforto térmico.

LED azul — Temperatura ≤ 18°C (frio)

LED verde — 18°C < T ≤ 26°C (conforto)

LED vermelho — Temperatura > 26°C (calor)

LED amarelo — Umidade > 80% (alerta)

desafio-03.ino

#include <DHT.h>

#define DHTPIN  4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

const int ledAzul     = 8;
const int ledVerde    = 9;
const int ledVermelho = 10;
const int ledAmarelo  = 11;

void setup() {
  Serial.begin(9600);
  dht.begin();
  pinMode(ledAzul,     OUTPUT);
  pinMode(ledVerde,    OUTPUT);
  pinMode(ledVermelho, OUTPUT);
  pinMode(ledAmarelo,  OUTPUT);
}

void apagarTodos() {
  digitalWrite(ledAzul,     LOW);
  digitalWrite(ledVerde,    LOW);
  digitalWrite(ledVermelho, LOW);
  digitalWrite(ledAmarelo,  LOW);
}

void loop() {
  delay(2000); // Intervalo mínimo do DHT

  float umidade  = dht.readHumidity();
  float tempC    = dht.readTemperature();

  if (isnan(umidade) || isnan(tempC)) {
    Serial.println("Erro ao ler o sensor DHT!");
    return;
  }

  Serial.print("Temperatura: "); Serial.print(tempC);   Serial.print(" C | ");
  Serial.print("Umidade: ");     Serial.print(umidade); Serial.println(" %");

  apagarTodos();

  // Controle de temperatura
  if (tempC <= 18.0) {
    digitalWrite(ledAzul,  HIGH); // Frio
  } else if (tempC <= 26.0) {
    digitalWrite(ledVerde, HIGH); // Conforto
  } else {
    digitalWrite(ledVermelho, HIGH); // Calor
  }

  // Alerta de umidade (independente da temp)
  if (umidade > 80.0) {
    digitalWrite(ledAmarelo, HIGH);
  }
}

O que foi aprendido

Competências técnicas desenvolvidas ao longo dos três desafios de automação.

Leitura de sensores — digitais e analógicos, com digitalRead(), analogRead(), pulseIn() e bibliotecas específicas como dht.read().

Lógica condicional — estruturas if/else if para tomada de decisão autônoma com base nos valores lidos.

Controle de LEDs — saídas digitais e PWM com digitalWrite(), analogWrite() e map().

Automação — sistemas que respondem ao ambiente de forma contínua e independente, fundamento da IoT e da eletrônica embarcada.

Testes e simulação — depuração com Serial.print(), validação de leituras no Monitor Serial e iteração de parâmetros no Tinkercad.

"Programar um Arduino é aprender a dialogar com o mundo físico — transformar dados em ação, sensação em resposta."
